# Домашній трекер запасів — бриф

## Проблема
Раніше запаси велись у групі в Telegram. Не працює, бо:
- з часом неможливо відредагувати повідомлення, щоб змінити кількість
- робити реплай на повідомлення для оновлення незручно

Потрібен окремий застосунок, зручний з телефону.

## Функціонал

**Картка товару містить:**
- фото (з камери телефону)
- назву
- де куплено
- ціну
- поточну кількість

**Дії з товаром:**
- велика кнопка "−1" при використанні — один тап, без реплаїв і редагування
- окрема форма "поповнити": плюсом кількість, за бажанням — оновити ціну/місце покупки

**Список товарів:**
- сітка/список карток
- сортування за принципом "закінчується" (кількість ≤ поріг)

## Технічний підхід
- Веб-застосунок (як попередній React-трекер циклу з localStorage) — не нативний додаток
- Встановлюється на телефон як PWA ("Додати на головний екран"): маніфест + іконка, повноекранний режим
- App Store / Google Play — свідомо не потрібні (для персонального використання це overkill; варіант із TWA для Android можливий пізніше, якщо знадобиться, iOS — суттєво складніше й дорожче)
- Дані — локально (localStorage) або через просте сховище ключ-значення

## Контекст користувачки
- Продуктовий дизайнер, робить речі під себе
- Вже будувала подібний персональний React-застосунок (трекер циклу з localStorage, фазові рекомендації, логування настрою)
- Хостить свої проєкти через GitHub Pages
- Працює переважно з телефону, тому UX має бути "в один тап"
